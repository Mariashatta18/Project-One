# Project-One

Python Project 1 - Student Assignment and Grade Tracker

## About the Project

This program is a Student Assignment and Grade Tracker. I created it to help organize courses, assignments, and grades in one place.

The program uses a menu where the user can choose different options. The information is saved in a JSON file so the data can still be available after closing and running the program again.

## Features

- Add a course
- Add assignments and grades
- View courses and grades
- Calculate the average grade for a course
- Check if the student is passing
- Save information to a JSON file
- Load previously saved information
- Exit the program

## How to Run

Run the `grade_tracker.py` file with Python and follow the menu options.
