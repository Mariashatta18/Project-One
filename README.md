# Project-One

Python Project 1 - Student Assignment and Grade Tracker

## About the Project

This program is a simple assignment and grade tracker for students. It allows the user to add an assignment, enter a grade, and view saved assignments.

The program uses a menu so the user can choose what they want to do. Assignment information is saved in a JSON file so it can still be available after the program is closed and opened again.

## Features

- Add an assignment and grade
- View saved assignments
- Save assignment information to a JSON file
- Load previously saved assignments
- Exit the program

## How to Run

Run the `grade_tracker.py` file with Python and follow the menu options.
