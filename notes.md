# Project 1 Notes

## Project Idea

For my first project, I want to create a Student Assignment and Grade Tracker. I chose this idea because as a student I have different classes and assignments to keep track of, so I want to make a simple program that can organize some of that information in one place.

## What I Want the Program to Do

The program should allow the user to:

- Add a course
- Add assignments and grades
- View courses and grades
- Calculate an average grade
- Show whether the student is passing
- Keep using the program until the user chooses to exit

## Design Ideas

I want to keep the first version simple and use a command-line interface. I plan to use variables for course and grade information, lists or dictionaries to organize the data, and if/elif/else statements to handle different choices.

I also plan to use loops so the program can work with multiple courses and grades. A while loop can keep the program running until the user chooses to exit.

## Possible Future Ideas

If I continue working on this project later, I could add assignment due dates, GPA calculations, missing assignment tracking, or the ability to save information to a file.
